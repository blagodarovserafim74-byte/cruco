# Cruco Code Tracker

Небольшое приложение на Tkinter для отслеживания изменений в кодовой базе: сканирует файлы, фиксирует изменения, отслеживает перемещения и показывает удобное меню выбора режима.

## Возможности
- Быстрое однократное сканирование каталога.
- Режим наблюдения с периодическим обновлением.
- Отслеживание добавлений, удалений, изменений и перемещений по хэшу.
- Настройки масштаба интерфейса, размеров окна и прав отчетов.
- Просмотр камеры и распознавание ArUco (требует `opencv-contrib-python` и `Pillow`).
- Генерация ArUco-кодов с сохранением описания и параметров.

## Запуск

```bash
python src/app.py
```

Для работы камеры и ArUco установите зависимости (можно также нажать «Установить» в окне ошибки):

```bash
pip install opencv-contrib-python Pillow
```

Если на Windows появляется ошибка доступа к `cv2.pyd`, закройте все приложения,
использующие Python, и запустите установку в терминале от администратора.
Также помогает предварительно удалить старый пакет:

```bash
pip uninstall opencv-python opencv-contrib-python
```

Если появляется предупреждение `Ignoring invalid distribution ~pencv-python`,
удалите старые файлы вручную из `.venv/Lib/site-packages` (папки `cv2` и
`opencv_python*`), затем повторите установку.

Или установите из файла:

```bash
pip install -r requirements.txt
```

Отчет сохраняется в `src/data/last_report.txt`, база состояния — в `src/data/tracker.db`.
Данные о созданных ArUco сохраняются в `src/data/aruco_data.json`.
